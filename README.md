# Experiment 7 – Android Application

## 📱 Project Description
This project is developed as part of the Android Application Development practical.

## 🎯 Objective
To create and implement an Android application using Android Studio and Kotlin.

## 🛠️ Technologies Used
- Android Studio
- Kotlin
- XML
- Android SDK

## ✨ Features
- Simple and user-friendly Android interface
- Activity-based Android application
- XML layout design
- Kotlin programming
- Android UI components

## 📂 Project Structure
The project contains the Android application source code, resources, layouts, and Gradle configuration files.

## ▶️ How to Run
1. Open the project in Android Studio.
2. Allow Gradle to sync completely.
3. Connect an Android device or start an emulator.
4. Click the **Run ▶** button.
5. Select the available device.
